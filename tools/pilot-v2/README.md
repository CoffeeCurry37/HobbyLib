在仓库根目录、Node.js 24.22环境中运行：

```text
node tools/pilot-v2/server.mjs
```

打开 [本机工作台](http://127.0.0.1:8791/)，进入“资料复核”逐条查看P001–P030。数据仅保存到 `work/pilot-300-v2/pilot-v2.sqlite`。关闭进程后重跑上述命令即可恢复。若端口被占用，先确认是否本工作台已经启动，不能误停其他进程。

首次在另一台机器运行，需要已有冻结输入 `work/pilot-300/samples.json`；没有时先按 [原工作台说明](../pilot-workbench/README.md) 运行 `node tools/pilot-workbench/prepare.mjs`，它核对原始种子，不重新抽样。源码的完整原始素材有访问限制时，先恢复受保护原件，不能造样本或换输入凑数。

可选环境变量 `HOBBYLIB_V2_PORT`、`HOBBYLIB_V2_DATA_DIR`；数据目录限仓库 `work/` 子目录。浏览器试填使用独立 `work/pilot-v2-ui-qa`，不算用户审核。原V1端口8789和原数据库不受影响。

## 实现边界

`model.mjs` 是本轮会话辅助查证结果的确定性整理器，不是已上线的自主搜索AI；P编号用于这批回归映射，不能直接推广为未来挂牌识别器。通用的身份冲突、套装范围、生命周期、幂等观察和审核保护规则可供下一轮开发复用；原rule-23匹配结果仍作为独立基线展示。

运行服务不读取生产凭证、不导入生产客户端、不对外抓取；只监听127.0.0.1。写入要求同源、随机令牌、JSON大小限制、预期版本/哈希；第三方文本以文本节点显示。没有生产写入接口、部署动作或自动运行后270条。它也没有复制用户完整收藏/拥有数据，不能声称已验证正式库的全字段迁移。

新增付费模型API调用0；本轮会话搜索、模型订阅及人工时间未完整计量，成本标为unknown，不能宣称整个研究免费。下一批开始前需接入逐请求/组/条耗时与成本计量。
