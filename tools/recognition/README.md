# 隔离识别管道 V3

当前实现在 `tools/recognition`，未替换线上扫描器。与工作台共用分类、系列身份、图片证据和永久目录归并函数；线上接入须另行授权。

- `core.mjs`：类型/作品分流、系列任务合并、身份冲突检查、幂等永久成员合并。
- `series.mjs`：读取带来源的官方页，提取FGOM卷次/封面/角色、LINK版本/店铺特典；威化5/6的官方编号图由本会话视觉读图转为结构化结果。
- `capture.mjs`：显式公开来源清单、域名/重定向限制、超时/尺寸限制、图片魔数检查、本地缓存和真实请求回执。遇到403停止该来源，不绕过限制。
- `prepare-capture.mjs`：只为100条开发样本及优先系列生成图片/资料请求。不存在常驻模型调用；视觉任务由本会话完成，未来可由模型适配器消费同样任务结构。
