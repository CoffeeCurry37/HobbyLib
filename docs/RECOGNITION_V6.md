## 正式规范

1. 作品、厂商、系列、活动先规范化再生成路径；同层、祖先和相关分支复用规范身份。大作品与 FGO 平行；书籍/卡片/周边从“综合”提到作品下。大型周边属于周边。Fate 玩具集中按类型（可动/静态/GK）、厂商、真实产品线、单品组织。其他 IP 玩具保持自己的作品。
2. 目录页只展示同层模块，商品仅在叶级；官方套装、随机盒、单品、临时卖家组合必须保留范围差异。临时组合回到所属系列；结束后退出当前展示但保留历史。永久商品零挂牌也保留。
3. 漫画、杂志、设定集、带卷号/裸数字的书籍和音像、一番赏、卡片、近期游戏、命名周边系列、活动商品触发系列查证；同人本轮不展开，GK 仅检图。按系列共享研究，避免每条重复联网。
4. 官方新增与扫描挂牌走同一身份入口。标题、商品号、媒介/版次/卷号、角色/卡号、图片、套装范围互相校验。店铺强标题可高于错配 ISBN，价格只作辅助。图文冲突进入待明确，不强行归并。图片取得与规则匹配不等于已核实。
5. 商品标题和简介描述商品本身，挂牌原文、价格、状态另存。简介 1–3 句，不随每次扫描追加。证据来源/时间与图片来源保留；已认可、已失效旧资料不重复查证。
6. 合并只处理同一商品身份；卷号、不同媒介、版次、卡面、单品/套装、特典/本体不能混合。同版不同平台仅聚合展示。关联改动与用户字段、Offer 历史、原编号必须完整保留；不把全库批量标成 verified。
