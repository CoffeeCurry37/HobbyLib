本轮在隔离300条上完成[13项反馈](PILOT_FEEDBACK_V5.md)对应规则和目录修正，正式扫描器、商品库及Site未改。实际数量、验证和剩余资料见[V5报告](../research/pilot-v5-20261101/REPORT.md)。V3/V4为历史结果，不能覆盖本版本。识图/公开搜索仍由会话辅助，不是已部署的无人值守服务。

## 根因与处理顺序

原问题来自多个适配器直接生成路径、旧对象缺大类字段、补全与挂牌分用匹配入口，以及界面允许模块和商品混排。正确顺序为：保留原观测 → 转换旧字段 → 规范作品/厂商/系列/活动身份 → 区分销售范围 → 全局查重/保留冲突 → 生成唯一路径 → 校验叶节点 → 展示。不能只修某个P编号或移动一张卡片。

- `tools/recognition-v5/taxonomy.mjs` 是统一规范与最终路由入口；`canonical-registry.json` 保存本次规范键、成员和旧链接别名。先查同层、祖先和相关分支中的全局键，优先复用模块。路径不是商品主键。
- FGO=Fate/Grand Order；Fate综合=Fate系列=『Fate』シリーズ。FGO、stay night、EXTRA、Zero、Apocrypha、kaleid等为平行大系列。EXTRA下面的EXTRA/CCC/EXTELLA/LINK/Record仍是不同作品身份。
- FGO的书籍、卡片、周边、音像、展会活动等直接展示；大周边归周边。Fate所有玩具进入Fate综合，按类型→厂商→正式产品线→商品。figma归Max Factory；粘土人、粘土人娃及服装复用GSC粘土人入口，原厂商品牌如ORANGE ROUGE另保留。未知产品线只标“未标注产品线”，不虚构系列。
- 旧对象只有中文类型或已认可路径时，先补大类。漫画、威化单卡不能因缺`identity.major`默认成周边；后续规则重建必须覆盖旧来源对象。
- 分支只显示模块，叶节点只显示商品。有必要时在同一系列下建立单品/官方盒装/随机包/临时组合等叶模块。搜索结果可以是商品列表，但不能与子模块混排。
- 活动名称优先于泛化“其他周边”，卖家拼包也回所属活动/系列；不另建混合套装总模块。跨IP未知拼包仍保留识图不确定性。

## 匹配与组合边界

官方补全成员和二手挂牌经过同一个`identity.mjs`入口。强键包括适用作用域内的官方SKU、规范系列+卷号、已证实产品线+角色，以及完整游戏版本。相同总图、同IP、相似标题不能单独确定身份；批次、卷号、职阶、地区、媒介、版本和销售范围冲突阻止合并。

同版游戏可以跨平台共用展示页，完整原身份在`sourceIdentities`、`variants`和原`offers`保留。PORTABLE、廉价版、店铺Collectors Edition、下载版、纯周边版和带手办版不因作品相同而合并。字段缺失不是通常版证据。Samurai三条TREASURE BOX挂牌共用页，PS5和Switch及各自JAN继续独立。

官方整套、随机BOX、随机单包、集换式已知单款和卖家拼套不是同一商品。BOX是否保证集齐必须有厂家说明；已知卡表只支持“可能包含”。多种特典在发行方同一栏并列而组合/可选关系未写明时，暂保留目录组，不臆造固定包，也不拆成可独立购买的成员。用户指定失效的临时页保持隐藏，永久零挂牌页保留。

标题/简介只描述商品。挂牌价格、成色、缺件在Offer，不借官方定价填历史报价。改版保留原报价及历史原文。P285的新图文冲突表明：店铺目录图也可能配错；相同角色不够，服装、比例、卡面须一致。冲突进入待明确，保留证据和挂牌，不自动绑定官方成员。

## 系列研究触发与来源

| 商品特征 | 研究范围与优先来源 |
| --- | --- |
| 漫画、小说、杂志/VOL/卷号 | 出版社系列页和单卷页；先确认真实卷数与发行媒介，不仅凭VOL2臆造VOL1资料 |
| 威化/集换卡/明确命名周边、vol/弹次 | 厂商产品线与本弹完整清单；HOBBY STOCK适合ぴくりる，BANDAI适合威化；保留批次 |
| 一番赏/在线抽赏 | 官方本场奖品页，至少明确各赏；奖项组与具体单款分开 |
| 游戏 | 发行商产品页的正式配置、地区/媒介、店铺特典；含多件或可选配置需店铺补证 |
| 展会/Fes/Comiket等 | 官方活动页与Aniplex同活动销售分类；入场礼、其他参展商和复刻另标范围 |
| 厂家玩具产品线 | GSC/Max Factory等官网的本体详情与特典图；复用规范系列和厂家名 |
| GK | 仅图片与当前身份，不自动扩展系列；同人出版物/一般同人周边仍不参加这轮 |

补全任务按规范系列合并，已经认可的旧资料复用。各任务保存来源、状态和预算建议（默认3次查询/8页/3分钟；当前为人工调度上限提示，不是已计费执行器）。生成查询词或加入队列不等于研究已完成。

补充来源经验：カーテン魂售罄详情仍可能保留标题和原图；ATFES需要分清BOX与1PCS的不同JAN；THEキャラ分类清空后，厂商自己发布的PR TIMES发售通告仍可作为一手历史资料，不能把媒体转载当官方。Cafe款和ミニキャラ款、亚克力卡与透明卡均分产品线。官方图片上的文字/双面箭头可以作为视觉证据，但要绑定图片哈希并写明会话转录；图变了不能沿用标注。

## 已实施边界与续做

本版本完成隔离规则、批次运行、来源适配、UI和记忆。新自动触发可覆盖未见标题；网络研究、图像转录和冲突判断尚未接常驻模型。不要把本轮反馈后的47项回归通过解释成真实准确率，也不要把全部目录标verified。

实际缺口由`remaining-gaps.json`导出：包括新200中33条缺图、历史证据不足的研究组、P285图文冲突、卡牌/徽章部分成员不明及5组游戏店铺特典的组合关系。后续优先按组处理缺口，不重复首30已认可/失效来源，不重跑旧32条与五边成功动作。正式接入仍需增量调度、费用计量、人工队列和生产字段保护，当前没有执行。
