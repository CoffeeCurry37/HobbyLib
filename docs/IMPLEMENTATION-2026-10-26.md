## B：决定、复查与评测

MatchDecision 包含规则版本、SHA-256 输入/决定 ID、来源键、候选、四态、原始证据/适用范围、冲突字段、稳定理由代码、证据等级及 observedAt。历史审计、摄取和只读人工复查共用 evaluateProduct/matchDecision；兼容 findProduct。默认同人 all 明确为策略，不作为一致证据。

矛盾观测进入稳定 review Item，保留其 Offer，不回写旧 Item；重复观测不产生新 review Item。歧义/冲突/资料不足不会因兴趣分数高而触发强推荐。无候选的新来源记录保留既有来源可靠度兼容策略；不扩大相似度自动匹配或自动归并。

24 条脱敏合成样本按来源/品类、独立系列及挂牌分组，分 tuning/holdout，检查跨 split 泄漏。5 次自动关联均正确，5 个正例全部召回，19/24 转复查，硬冲突误匹配 0；precision Wilson 95% 区间约 [56.6%,100%]。**这不是生产准确率；尚无真实人工标注留出集。** 分来源/品类样本与不确定性见 [完整评测](reports/identity-20261026/synthetic-evaluation.json)。

## D：增量、事件与报价

identity-shadow API 只读、不请求来源、不调用 stateFor 的历史迁移；它标明旧路由近似比较。离线脚本加载完整 main 基线模块，与当前完整规则比较，24 条中 18 条目标变化，零数据库写入。合成变化数量不代表线上改进率。

摄取先暂存写入，再原子校验 Item/关系/偏好并提交 Offer 和通知。两次并发扫描只允许一个提交，另一方返回忙碌/版本冲突；旧数据不覆盖新数据。scoped import 分页覆盖必要索引候选，Sites/standalone 的 compact 导入共用此路径。

通知数据库以 (user_id,id) 唯一保存；stateFor 只读取最近 300 条，没有“数据库仅保存 300 条”的结论。Offer 事件序号/类型随备份持久化，因此已读、窗口外和删除后的旧事件不重放。测试覆盖首次挂牌/核验、同批重放、并发扫描、降价→恢复→再次降价、售罄→补货、套装包含明确缺件；未知拥有状态不当作缺件。没有邮件或外部推送。

报价保留 [0,24h) 核验窗口，排除未来核验与结束拍卖；按成色、附件、税制及出售形式分组。竞拍价不当即售价，整套价不当单价，历史挂价不当成交价/市场公允价；税制未知不再获取“同税费降价”加分。未知费用、到手价与汇率保留 null，不默认 0。
