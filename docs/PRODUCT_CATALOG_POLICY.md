# 商品目录、收录与简介规则（首批用户反馈版）

2026-10-30。来源：用户对P001–P030的15点审核。本文是已确认的产品方向及明确标注的实施建议，**尚未改动生产模型或页面**。逐项记录见[PILOT_FEEDBACK_2026-10-30.md](PILOT_FEEDBACK_2026-10-30.md)。与早期设计冲突时，以本次具体反馈为准；数据保护和历史证据仍保留。

## 1. 一级、二级页面与身份分开

一级按用户要浏览的商品系列/作品/发行组组织：turas réalta漫画、FGO威化第14弹、Fate/EXTELLA游戏。二级分三栏：**正式商品/版本、可独立收集的特典、当前临时组合**。每栏是否出现取决于实际发行事实，不强制每个系列都有特典。

- 永久页面：正式发售过的单册、独立商品、可独立收集的系列成员、已证实的游戏版本、符合下述规则的游戏店铺特典、活动商品。零挂牌也保留，不能显示“未找到挂牌=缺货/未发售/还缺”。
- 临时页面：卖家拼套、描述清楚的卡片组合、混合大包、低研究价值的兑换码、用户指定的figma店铺特典等。展示当前可售对象，生命周期跟随实际挂牌。
- 数据身份与页面不等同：同一版本的不同游戏平台可以在一个二级页面内用选项/分组报价展示；底层仍保留平台、实体/下载媒介、版本、SKU、Offer、特典适用条件及原Item ID。未知平台不与已知平台强配，也不混算最低价、拥有或缺件。
- 多个目录入口指向同一身份，不复制商品。厂商/品牌→figma、ねんどろいど等产品线是导航模块，区分制造商、品牌、销售商，不把全部产品都视为同一厂商制造。
- “三个同名雷达项目”进入重复/展示检查：若仅平台不同，可统一页面展示；若身份完全相同且确实重复，再出可撤销归并方案。不能直接删掉两个ID。

## 2. 永久目录与临时挂牌的生命周期

临时页不按卖家原始标题永久建档。建议用受保护的临时视图或单独生命周期字段，复用底层商品和Offer，避免重写全部Item模型。

1. 发现漫画1–22卷拼套：在系列一级页“当前套装”建立临时条目，范围明确为1–22。单册1–22继续使用各自永久页；一个套装总价只属于该套装。
2. 出版社证实第23卷：先查现有/待建身份，按正确单卷ISBN和版本创建或复用永久页。不能把23卷加进1–22套装。
3. 临时条目下所有有效挂牌都明确售罄/结束：从默认浏览和当前套装栏撤下临时页，后台保留可追溯存档、Offer历史、人工判断和重上架线索。用户所说“删除临时页面”按撤下可见页实现，不删除永久成员或个人记录。
4. 404、登录墙、超时、解析空页仅记不可访问/待重试；不当作已售证明。页面可标“不确定是否仍在售”，不能继续当已核验库存推荐。
5. 多来源还有可售挂牌就保留临时入口。再次上架按来源键与内容重新核对，避免重复页，也不因相似标题跨卖家强配不明拼包。
6. 永久商品售罄后仍存在；确认目录成员无Offer也可发布。“身份已知”“资料完整”“当前在售”是三个独立状态。

## 3. 收录决策与拆售边界

| 情况 | 目录政策 | 例子/限制 |
| --- | --- | --- |
| 官方单独发行、系列中可独立收藏的成员 | 永久页 | 单册、手办、Aniplex活动商品 |
| 集换式/随机卡或徽章的单款 | 永久页 | 威化单卡；不要求每张都有挂牌 |
| 卖家把独立成员重新拼成套 | 临时页，关联成员 | 漫画1–22卷、卡多克+贝里尔两张卡 |
| 官方原本固定整套出售、无独立收集机制，卖家只拆出其中一件 | 不新增该拆件商品页 | P028若证实属于这种固定套装则排除；P030印画按此规则不新增独立页 |
| 官方固定套装整体出售但缺件 | 母版本永久页＋缺件Offer；必要时临时入口 | P029仍是VELBER BOX，保留缺PS4游戏的状态，不能显示齐套 |
| 已查清且适合独立收集的游戏店铺特典 | 游戏下“特典”永久页 | P015的Amiami挂画；必须先确认特典及适用作品，失效卖家链接不取消官方特典事实 |
| 手办官店附赠配件 | 本体描述保留特典事实/参考图，单卖入口临时 | 用户明确指定P020；不把这条扩张为所有游戏特典都临时 |
| 低研究价值的单次兑换码 | 临时页 | P014；不承诺未用、有效、可兑换 |
| 成员无法低成本拆清的大包 | IP下“混合套装”临时模块 | P026；不必穷举全部人物、件数与成员 |
| 无线上售卖页的入场特典 | 可先作待确认系列；证据足够再永久建档 | P025；不能因Aniplex没卖就判不存在 |

固定套装拆件规则是**新收录政策**，不授权批量删除历史商品、个人收藏或证据。现有P030候选先保留卖家错名的纠正和原观察，标记“不新增独立组件页”，其印画可记于官方盒装内容。手办服装若官方本来单卖（P018）仍是永久商品，不属于拆售排除。

P028须先查官网/店铺：是完整官方特典组合、普通系列成员，还是固定组合的部分拆售。不能因“2个set”几个字直接收录或排除。

## 4. 来源权重按字段决定

- 骏河屋、Mandarake商品局部标题的明确卷数、套装、缺件、版本描述权重高。P005“1–22巻セット”可覆盖误借单册ISBN对销售形式的误导；保留两条原证据并标注ISBN属于单卷。
- 这不是“可信店铺所有字段永远正确”：出版社/厂商的发行身份和单卷ISBN仍是核对依据；两个明确身份事实冲突时进入审核，不静默丢掉冲突。
- 价格作低成本佐证，不作身份结论。约9000日元可以支持多卷套装假设，但稀有单卷也可能昂贵；竞拍起价不代表商品价值，不能设“超过某价必定是套装”。
- Mercari/Yahoo内容质量不稳定，按每条标题、说明、实拍、历史观察分别判断，不能全盘拒绝或全盘采信。P027清楚的“两张卡组合”可以确认出售范围，仍不代表各卡弹次自动确定。
- 交叉历史挂牌需检查独立来源、图片、时间、规格；同图转卖、搬运或转抄不算独立确认。P025用户确认“入场特典、不线上贩售”作为用户领域证据保存，正式系列建档仍按证据链/人工审核流程。
- 官方页缺失时可用可靠卖家记录建立有限字段，未知的来历、购买条件不补造。低风险临时条目不必为了全字段齐全无限研究。

## 5. 图像与角色区分

库丘林不能只按名称归并：角色、职阶、形态、卡面、产品线、弹次和印刷卡号分别保存。P010卡背可见Caster与N07；先核对候选弹是否收录该职阶，再比较图案、卡背和编号。

可使用Mooncell/Wiki辅助核对角色立绘、职阶、再临形态与别名，保留具体页、图及版本/访问日期，明确为社区证据。Wiki确认立绘不等于确认这张商品卡的弹次、稀有度或官方发行；官网卡表/参考图与实物卡背仍需对应。社区图不默认可复制托管，优先保存链接和来源。

先读清晰文字/背面，再对有限候选识图；同角色不同弹次必须能拒绝误合并。卖家链接已失效时使用既有合规快照；没有图就保留未知，不声称看过当前实物。

## 6. 商品简介：1–3句话，稳定且有证据

正文优先包含：是什么类型＋属于哪个作品/系列/卷次；若影响身份则写活动/周年/购买/入场等发售条件；最后补核心内容、代表角色或关键配件。没有证据的发售条件不硬填。

- 资料集：系列第几卷、资料类型、代表收录人物；完整角色表留在结构化收录关系，简介不罗列几十个名字。
- 官方漫画：明确漫画改编/作者/卷次，以出版社内容为依据用一句话概括剧情；不得将游戏主线背景知识冒充该卷剧情。
- 活动周边：活动名称与年份、品类、角色/规格和销售方式。发货延期、预订期分字段记录，不挤成冗长正文。
- 手办：系列/厂商、人物、造型版本、比例等；存在官店特典时简洁注明，明确不代表每个二手挂牌都附送。
- 拼套：范围、件数、明确缺件；不复制卖家营销话术、价格变化和上新日记。

资料新增时按事实差异合并并重新生成同一段简介，已有事实不重复添加；长度和句数受控，禁止“每扫描一次追加一句”。新字段有证据才能加入，矛盾先审核。自动简介和人工编辑分开存；用户修改过的正文先出差异建议，不直接覆盖。证据、完整标签和更新历史放独立区域。

## 7. 研究成本分流（下一阶段实施建议）

- 快路径：读缓存目录、既有事实、可靠标题和说明，判定已有身份/明确拼套/缺件；不再重复全网查。
- 系列路径：一次研究一个漫画系列、威化弹次、活动款式或游戏版本/特典目录，多挂牌共用证据。优先补能被长期复用的永久目录。
- 视觉路径：只在同名人物、不同卡面或版本无法消歧时，查官方图、卡背/OCR，必要时借助Wiki。
- 临时低优先路径：低价值且难复用的兑换码、大包保留足够分类和未知项；达到有限检索上限后停止，转临时/人工，不无限升级昂贵研究。限额数值先作为配置建议测量，不能当用户已授权的付费预算。

同时记录来源请求数、缓存命中、研究组复用数、模型成本与人工分钟；没有付费调用时仍报告人工/会话成本未知。不得只用竞拍起价决定研究价值。
