# V4反馈与通用识别规则

来源：用户在V3交付后的11项反馈（2026-10-31）。最新授权：修正这些问题后继续原200条扩展实验；同人暂不参与；正式商品库和网站不改。旧“200不运行”边界在本轮已被明确更新。

## 11项反馈的执行映射

1. 详情图失败须查实际原因。已失败的URL不继续当图库图片展示或计入有效图数；保留错误诊断，优先官方本体图和已成功的系列图。
2. “历史挂牌”不证明保存过价格。区分已售来源未保存售价、市场聚合页未有单店报价、采集缺字段、有效历史报价；仅从同一Offer/观察原文恢复价格，不把定价、当前售价或聚合最低价填成旧报价。
3. P049是SE.RA.PH漫画1–8卷临时拼套；触发整部作品卷目补全，单册永久、拼套临时，继续检查后续卷。
4. P052是カルデアエースVOL.2；有卷/号信息的杂志、mook和fanbook同样触发期刊系列，查VOL.1及官方后续。
5. 用户认可系列总图。允许总图先覆盖无特写的成员，明确图的范围，后续来源增加单品图，不因无特写拒绝合理永久成员。
6. 展会/活动/Comiket按事件+年份+主办/销售方归组，优先Aniplex活动页、活动官网和官方X。Aniplex不必然涵盖入场赠品或全部参展商，不能把一个销售页说成全活动全集。
7. 由特典/系列扩展发现的商品，与挂牌触发商品执行同一资料完整度检查。figma370须查官方本体图、作品/厂商/编号/尺寸/发售信息/附件及独立官店特典，不能只有替换脸图。
8. 一番赏按具体弹/活动触发奖项全表，至少查清A/B…/Last One各赏是什么。奖项组与随机单款分层；款数已知但成员未知不能凭数量造名。
9. 商品标题和简介只讲商品。起拍价、成色、未拆、运费、库存、卖家编号、抓取话术存Offer/原文，不进入永久商品标题/简介；型号、正式版本、正常附件、比例和卷次保留。
10. 同人采用独立关注社团逻辑，暂退出本轮整理、查证和系列扩展。保留原记录与排除原因，不删除、不擅自猜关注社团；200分母中明确记录跳过数量。
11. 规则必须由商品特征触发，不能按P编号逐个补丁。记录触发条件、来源优先级、完整性、预算、失败与复用原因；识别系统和系列衍生商品共用。

## 来源矩阵（字段用途优先，而非网站全局可信度）

| 资料 | 首选 | 次选/限制 |
| --- | --- | --- |
| 书/漫画/杂志卷目、ISBN、出版日期、封面 | KADOKAWA/讲谈社/TYPE-MOON等出版社及官方连载页 | Amiami、骏河屋、Mandarake补充；套装ISBN不当单卷ISBN |
| 手办本体、编号、配件、尺寸和图片 | GSC/Max Factory/Alter等厂家产品页 | Amiami同SKU可补图；官店特典图单独标注，不能代替本体主图 |
| 活动商品与变体列表 | Aniplex Online活动页、活动/主办官网、官方X | 按届次和销售范围判断完整性；入场品交叉来源或待核实 |
| 一番赏/集换系列 | BANDAI SPIRITS一番赏、Bandai Candy、发行方官方表 | 官方限访保留证据缺口，官方发布稿/官方X补足；二手目录只作相互佐证 |
| 游戏版本/店铺特典 | 游戏官网发行矩阵、店铺特典页 | 底层平台/地区/媒介独立；同版共页不合并报价身份 |
| 图片 | 厂家/出版社图库→官方活动总图→同商品编号店铺图→卖家实物图 | Amiami图源本机多次403，不循环重试或绕过；骏河屋同商品编号CDN可作备选，不能按猜编号替换 |
| 拼包/未知实物 | 原挂牌照片与描述，按区域读图 | 可见件数不等于出售数量；图片无法判断的成员/完整性保留未知 |
| 当前/历史价格 | 同一Offer对应观察和原文 | 官方定价、市场区间、其他店价格分别存储，不填补不存在的历史价格 |

## 自动触发与停止条件

漫画/小说单卷或卷区间、VOL/第N号/罗马卷号、集换弹次/全N种、活动名+年份、明确一番赏名、游戏正式版本/特典、手办产品线/编号均生成研究组。无卷号不代表无需系列调查；已知作品/发行组可复用来源。实体类型先判定，CD/DVD卷不能套用漫画逻辑；宽泛Fate关键词不等于TYPE-MOON（例如WINX、奈叶的菲特）。同人先排除。

查证任务按规范系列身份共享；发现永久成员递归执行基础资料检查，但不无限扩展整个厂家或整个IP。每组有来源/请求上限、截止状态与完整度；已确认资料不重复复核。结果状态必须区分已确认完整、部分已确认、来源限访、身份未知，不把已生成搜索词算已完成研究。

本轮200是收到开发反馈后的扩展实验，不作独立盲测准确率。原拆分/编号不修改，记录与已研究系列重叠；不伪造独立答案，不将规则预测自动写为verified。程序、证据、成本与结果及时推送GitHub。
