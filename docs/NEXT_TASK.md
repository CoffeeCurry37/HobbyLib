- 原队列为 1,848 组、9,795 个不同历史 ID；这是研究候选覆盖，不是已核实数量。使用稳定分组键、完成快照与归并映射，不重建或丢弃原编号。
- 官方总目录 → 商品/版本 → 逐字段证据。活动目录不保证包含赠品、其他参展商、已下架或再版商品；年度复售不能推出首发年份。厂商、作者、承售方、同期报道和留存零售资料分开标注。
- 原网页与图片缓存、完整目标和请求放本机受保护 work 目录。GitHub 仅保存脱敏事实、URL、时间、哈希、匹配理由和缺口，不提交个人库或凭证。
- 只在五项 checks 和来源匹配均满足、无未决项时标 verified。简介补齐、抓取、图片 HTTP 成功不等于完整核实。当前完整核实数仍为 0。
- 保留人工字段、认可状态、收藏、数量、优先度、备注、图片、报价历史、关系与偏好。写前完整读取实时目标，使用 expectedVersion，最多 20 条一批，写后逐条读回并即时保存回执；变动目标跳过或重新独立审查。
- 新拆分、归并、Offer 迁移需具体方案并先在完整副本验证；本轮无此类操作。同人排除，GK 只检图。
- 不绕过登录、验证码、年龄确认或访问限制。缓存优先；公开索引观察哈希不能冒充原网页哈希。
