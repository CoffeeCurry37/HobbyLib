## 3. 统一身份决定与评测

实现可解释 MatchDecision，建议字段与四态见商品契约。保留输入指纹、规则版本、候选与冲突、来源证据、reasonCodes 和目标 id。保持已有 findProduct 调用兼容，逐步迁移；决策在 ingest、副本审计与人工复查中复用。

硬冲突优先于相似度；标识只在其作用域内可靠；未知不代表一致；随机款共 JAN、卡面、平台、媒介、卷号、本体/特典、原厂套装/卖家拼套分别处理。matched 要求唯一可靠目标；ambiguous/conflict 保留来源观测并进入复查；unmatched 依据来源可靠度创建待确认或正式条目，不能默认为已核实。

准备脱敏、可版本管理的测试夹具和人工标注格式。按来源、书籍/游戏/卡片/周边/同人分层，分开调参集和留出集；同系列或相同 Listing 不跨集合泄漏。至少覆盖以下行为：

| 输入 | 必须结果 |
| --- | --- |
| 同版不同店铺与成色 | 同商品、独立挂牌，成色保留 |
| 同 URL 但卷号/媒介/平台/组件冲突 | conflict，不覆盖旧商品 |
| 缺失 itemCode 的不同来源页面 | 不共用可匹配 Listing 键 |
| 原版小说、文库、漫画、不同 ISBN | 保持独立，可建立关系 |
| 本体带特典/缺特典与特典单品 | 本体同身份时挂牌附件不同；特典独立 |
| 同 JAN 一番赏不同赏别/款式 | 不误匹配 |
| 卡牌不同卡面、再版或活动版本 | 按证据区分，不仅看角色 |
| 共用泛别名但有两个不兼容目标 | 歧义或以可信标识消歧，不能任取 |
| 卖家拼套、原厂盒装、系列父级 | 三者不合并，内容未知保留 |
| 同人同社团同名与明确版本冲突 | 复用现有例外，冲突不被默认分级消除 |
| 旧观测重放、新 sold、sold→available | 不倒退；售罄立即生效；补货事件独立 |
| 指纹过期、并发用户编辑、归并后编辑再撤销 | 拒绝过期覆盖，保护用户数据 |

报告自动关联 precision/recall、待复查率、硬冲突误匹配、分来源样本数与置信区间。合成用例全通过不能替代真实标注评测。没有足够标注时仅交付影子/建议模式，自动启用阈值作为待决策项保留；不能自设一个高百分比就宣称可靠。

## 4. 历史商品的有界审计与层级/标签计划

新增或扩展只读 dry-run 命令，输入显式快照路径和范围，默认不写数据库；复用现有 editorial 投影与索引，不默认加载 228 MB 全备份到模型。读取需分页，支持游标和断点、规则版本与输入哈希。避免全库两两比较，记录最坏候选桶和耗时/峰值内存。

输出稳定 JSON/JSONL 与简明 Markdown：每条原编号和 Item id、候选目标/原发行目录、判定与证据、硬冲突、建议产品线/版本/成员、目录路径、标签增删来源、关系差异、待查问题。分组只复用共同事实，每成员单独验证身份与图片；不复制 ISBN、日期、图或特典至未验证成员。

层级参考“作品/IP→媒介/品类→产品线/发行系列→版本/款式”，以现有 catalogueGroup 和目录字段兼容实现。逻辑分组与物理 contains 明确区分。对原版 Prototype 小说 #486–490 等已知混目录问题，只生成有证据的重归类计划，验证父级、原关系、覆盖范围后提交审阅；不要顺带执行生产修订。

用已确认厂商目录核对成员范围；“目录未收录”和“未拥有”分开。推测成员保留 inferredMember/provisional，不用推测补齐库存。保留 15,811 固定编号、42 partial 和既有批次状态，最新状态优先，绝不重新编号或重放 001–004。

标签复用结构化字段与现有 metadataTags，新增受控词表和别名映射时兼容 string[]。人工标签来源不明时保留；自动生成的分类/标签变更记录字段证据、规则版本和理由。严禁用导航词、搜索词或兴趣偏好推定商品身份。保留无明确成人提示时的既有 all 策略，并区分默认策略与来源事实。

可选 AI 适配器只处理规则无法解决的小批疑难项，默认关闭，需缓存、超时、预算、结构校验和来源引用。未经用户另行配置不接入付费 API，不把个人字段送入外部模型。模型无权绕过冲突或写生产数据。

## 5. 增量、通知与价格

增量与历史共用身份决定；先增加影子开关，记录旧/新判断差异，不改变现有生产摄取行为。离线重放同批观测及乱序输入，验证无重复 Item/Offer/关系，来源验证要求能暂停并持久恢复。修改数据库模型需新增迁移和副本升级/恢复测试，不改写已应用迁移。

专项验证现有提醒读取窗口、保存唯一性与裁剪行为，再设计持久事件幂等。分别测试新挂牌、降价、价格恢复后再下降、补货、套装含所需单品、两个扫描并发、旧任务重放与已读提醒裁剪。兴趣分数不能替代身份可靠度；疑难匹配不产生强推荐。无配置外部渠道时继续应用内提醒，不声称已发邮件。

保留 24h 报价核验及过期/未来时间检查，建立成色、附件、税费口径与成交形式的可比性结果。竞拍价、即决价、整套价、历史挂价分别标识。先展示 JPY 同版报价与费用缺项；有实测数据后再加到手价区间和汇率时间。不得把历史最高挂价作为市场公允价或承诺最便宜。
