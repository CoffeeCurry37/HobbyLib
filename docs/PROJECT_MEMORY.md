## 产品目标与用户偏好

HobbyLib 是商品知识库，Collector Radar（收藏雷达）是当前正式界面。二手挂牌是发现商品和丰富资料的来源，不能成为商品身份、标题和简介的主体。需要解决历史商品整理和未来新挂牌识别两条链路：判断具体商品、发行方式、同系列成员、关联特典、角色/画师等标签，并优先匹配既有商品避免重复。

保留收藏雷达原有模块层级和视觉。规则必须泛化，不能用户指出一个P编号才修一个。用户不希望为已经授权的常规修复反复确认；及时提交GitHub检查点，避免会话用量限制导致成果丢失。旧认可和指定失效的资料不重复研究。本轮已完成用户指定的两组补证；后续继续依据最新用户请求及断点执行。

## 已确定的业务规则

- **目录**：先规范作品、厂商、系列和活动身份，再生成路径。全局检查同层、祖先和相关分支，优先复用现有模块。FGO与Fate/Grand Order是同一作品；Fate综合、Fate系列、『Fate』シリーズ是同一总入口。stay night、EXTRA、Zero、Apocrypha、kaleid等大作品与FGO平行。综合只放不适合独立大模块的小分类。
- **层级**：模块与模块同级，单品与单品同级；目录分支只展示模块，商品放叶模块。书籍、卡片、周边、音像等直接挂作品下；大周边属于周边。必要时在同系列下用单品、官方盒装、特典、临时组合等叶模块区分范围。搜索列表不受目录层级限制。
- **玩具**：Fate玩具集中在Fate综合，按可动/静态/GK→厂商→真实产品线→商品整理。Max Factory/figma、GSC/粘土人复用统一入口，粘土人娃和服装不再另造重复系列。其他IP保留自己的作品。GK只优先找图，不自动扩展系列。
- **永久与临时**：官方发售的独立商品、书籍单卷、集换式单卡、已证实活动商品可永久保留，零挂牌也不删。卖家自组的漫画1–22卷套装、两张卡拼套、杂项拼包是临时对象，放回所属系列；确认结束或用户指定失效后退出当前展示，保留历史。链接失效不能单独推定已售。官方固定整套被拆卖，默认不新增独立商品；特典及例外遵循商品政策，不以“set”单词直接判断。
- **游戏与版本**：EXTRA、EXTRA CCC、EXTELLA、EXTELLA LINK、EXTRA Record是不同游戏。通常版、各类BOX、店铺配置也要区分。用户不在意同版游戏的PS/Switch平台分成多个展示页，可共页，但原平台/JAN/地区/配置及挂牌保留。DVD与Blu-ray仍是不同商品身份，不能沿用游戏的展示合并规则。
- **特典与组件**：本体、特典、套装、独立成员的拥有状态分开。EXTELLA店铺挂画等明确官方特典可建永久资料；低价兑换码、证据不足或用户指定的官店特典可临时展示，并在本体说明中保留特典信息/图片。不能把“所有特典永久”或“所有特典临时”当统一规则。
- **同系列搜索触发**：漫画、小说、杂志、设定集、VOL/卷号，以及已判定书籍/音像标题中的裸数字；卡片/威化的弹次；一番赏各赏；近期游戏的版本和预约特典；明确命名周边系列；Fes/Comiket/展会活动。VOL2或第3卷是研究信号，不是凭空造出其他卷资料的证据。年份、数量、价格、比例和PS4/3DS不当卷号。同人按用户关注社团另走逻辑，暂不参加这轮补全。
- **身份与去重**：规范作品+产品线/卷号/弹次/角色职阶/卡号/媒介/版次/销售范围结合官方SKU、标题、图片和说明交叉判断。相同总图、同IP或标题相似不能自动合并。Mandarake/骏河屋的明确套装标题通常很强，错配ISBN不应压过清楚的标题；价格仅为辅助。图文矛盾、同名不同职阶、缺件、版本不明转待明确。
- **简介与标签**：简介1–3句，描述商品类型、系列卷次、发售背景和重要内容；书籍收录角色或剧情只写有依据的信息。不要每次新挂牌就追加一句。价格、成色、缺件、库存、卖家原文单独留在挂牌。角色/画师等标签要有证据；不要用推断标签使已认可的审核依据失效。

## 资料和图片来源经验

| 类型 | 优先查证资源与注意事项 |
| --- | --- |
| 书籍/音像 | 出版社、动画/发行商官方单卷页与系列目录；有商品号、卷号和媒介再补全 |
| 手办/粘土人/figma | 厂家官网，必要时amiami等授权零售商；同时找本体详情图和单独特典图 |
| 威化/卡片/命名周边 | BANDAI、HOBBY STOCK等官方完整清单；没有单款图时可明确使用全弹总图 |
| Fes/Comiket/展会 | Aniplex Online同活动目录和活动官网；入场礼、其他参展商、复刻不保证在Aniplex有售 |
| 一番赏 | 官方本场奖品页，至少明确每个赏；奖项组与具体单款区分 |
| 游戏 | 发行商版本列表及各店官方特典页；不臆造组合/可选关系 |
| 历史资料/图片 | 厂商官方X、厂商自己发布的PR TIMES通告、保留页面的零售商；Wiki/Mooncell辅助辨角色，不能替代官方发行事实 |

图片保留来源、抓取状态和必要指纹；历史挂牌失效优先复用保存的图片与原文。拼包可尝试识图分区，不能把分割候选直接当确定成员。源图打不开要明确缺图，不伪造图片；官方图403不绕过，可使用确切对应的合法零售商图并标注来源。官方补全的新成员与扫描发现的商品应经过同等身份、资料和图片检查。
