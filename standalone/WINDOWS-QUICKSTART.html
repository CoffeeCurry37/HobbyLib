先打开你的商品库

v0.14.0 · 本地完整包已经带有商品数据库。普通浏览不需要安装浏览器采集组件。

1. 安装 Node.js（只需一次）

如果提示 Please install Node.js 24 or newer，表示未找到所需运行环境，商品数据没有因此被删除。

  1. 打开 Node.js 官方下载页。
  2. 选择 Node.js 24 LTS → Windows Installer（.msi）。普通 Intel / AMD 电脑选 x64；Windows ARM 电脑选 ARM64。
  3. 运行安装程序，保留默认安装路径和 Add to PATH 选项。无需另装 Python，也无需勾选编译工具。
  4. 安装完成后关闭旧的启动窗口。新开命令提示符，输入 node -v，应显示 v24 或更高。

2. 启动与登录

  1. 右键 ZIP → 全部解压。进入解压后的 collector-radar 文件夹；不要在压缩包内运行。
  2. 双击 START-WINDOWS.cmd，保持黑色窗口打开。
  3. 浏览器打开 http://localhost:8080。
  4. 在程序文件夹的 data/studio-password.txt 中复制首次启动生成的密码，粘贴到本地登录页。不要把密码发到聊天里。

关闭黑色窗口会停止本地服务。在线版和本地版各自保存，不会自动同步。

3. 以后需要动态网页采集时

先关闭正在运行的程序。双击 SETUP-BROWSER.cmd，等待联网安装完成；再双击 START-BROWSER-WINDOWS.cmd。这一步下载额外浏览器，普通浏览与整理商品可以跳过。

遇到问题

安装后仍提示缺少 Node：重新打开启动窗口；新版还会检查默认安装目录。若 node -v 仍失败，重启 Windows 后再试。

网页打不开：检查启动窗口是否报错，确认已使用上面的完整地址且程序窗口未关闭。端口 8080 已被旧版本占用时，先关闭旧版本。

升级：新完整包请解压到新目录。若旧本地版已有新标记或备注，先在旧版导出备份并保存整个 data 文件夹，勿直接覆盖自己的数据库。复制旧 data 到新程序前，先退出两边程序。

本版完成了 Linux 上的启动与真实数据库接口测试；Windows 启动脚本尚未在 Windows 实机运行。
