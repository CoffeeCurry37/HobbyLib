# 收藏雷达 v0.14.0：本地使用与后续更新

完整包包含核验后的在线商品库、可恢复的合并存档、报价来源、关联、个人备注和收藏状态。实际记录数及采集断点见 release-info.json。无需先导入旧库。

## Windows 启动

1. 安装 Node.js 24 或更高版本：https://nodejs.org/en/download 。选择适合电脑的 Windows Installer（通常 x64），保留默认路径与 Add to PATH。安装后关闭旧启动窗口。
2. 把 ZIP 全部解压到固定目录，进入 collector-radar 文件夹。先打开 WINDOWS-QUICKSTART.html 阅读图文步骤。
3. 双击 START-WINDOWS.cmd，保留程序窗口。浏览器打开 http://localhost:8080 。
4. 在 data/studio-password.txt 复制首次启动生成的本地工作室密码并登录。

提示 Please install Node.js 24 or newer 表示未找到运行环境，不代表数据库丢失。新开命令提示符运行 node -v，应显示 v24 或更高。浏览和整理商品不需要安装可选浏览器组件。

macOS / Linux 在解压目录执行 node start.mjs。图片保留原站 URL，需要联网；本地包没有下载所有原站图片文件。

## 采集、提醒与商店账号

本轮公开入口已尝试 Mandarake、骏河屋、AmiAmi、Mercari、Yahoo、Melonbooks、Toranoana、BOOTH。成功取得的挂牌已入库，失败原因与分页断点保留；这些结果不代表全站历史数据已经收齐，也不代表当前仍有货。

后台监控默认关闭。可在本地“采集工作台”配置并启用；关闭网页后程序必须仍在运行。加入关注仅保存提醒条件，后续成功采集并确认满足条件后才产生提醒。本在线站点没有启用全天云端定时任务。

需要动态网页或商店会话时，先关闭程序，运行 SETUP-BROWSER.cmd 安装可选组件，再用 START-BROWSER-WINDOWS.cmd 启动。在应用已支持的商店入口打开浏览器，由你手动登录；程序把会话保存在本机。验证码、双重验证和过期登录仍需你处理。这不等于所有网站均已支持自动登录。

在线站点不能直接继承电脑浏览器的商店 Cookie。本地模式能保留支持入口的独立会话，但不会解决原站所有访问限制。不要分享商店密码、data/browser-profiles、studio-password.txt 或 session.key。

## 保留自己的数据

在线与本地使用独立数据库，不自动同步。使用本地后，以你实际维护的库为准。

升级时先停止旧程序并备份整个 data 文件夹。新包解压到新目录，用自己的旧 data 替换新包的初始 data，再启动。不要用本包初始数据库覆盖后来新增的收藏和备注。也可通过应用导出完整 JSON，再恢复到空库。复制 SQLite 前先停止程序，避免遗漏 WAL 文件中的最新写入。

完整包附有更新前备份 PREVIOUS-DATA-BACKUP.json.gz；它是恢复资料，正常启动无需导入。合并存档保存在当前数据库中。
