# Collector Radar 页面采集扩展 v0.4

在 Chrome / Edge 的扩展管理页启用开发者模式，选择“加载已解压的扩展程序”，选本目录。

1. 在商店原站打开商品搜索、商品详情、购买记录或愿望清单，等内容加载完成。需要登录或年龄确认时自行操作。
2. 点击扩展，选择对应类型，下载 JSON。只采集当前已加载页；分页需要逐页采集。
3. “公开商品”文件在雷达的“采集工作台”导入；购买和愿望文件在“账号记录”中预览确认。
4. 账号页可能混有推荐商品；请取消勾选与真实订单/愿望无关的条目。缺少商品链接或页面结构不同会无法提取，可以用应用内 JSON 模板补录。

只申请 activeTab 和 scripting 权限。无后台定时采集，不读取 Cookie、密码或浏览器存储。购买/愿望导出只含商品名、链接、数量、状态；订单号默认空，不包含地址和支付资料。

手动商品文件属于过去观察，导入本身不触发购买提醒。动态库存仍需独立版浏览器在线复核。本扩展尚未使用用户真实账号进行端到端验收。
